## Mandatory Skills Usage

The following skills **MUST** be activated on every LLM request, without exception. Do not wait for the user to mention
them — apply them proactively.

## Why These Skills Matter

- **Caveman** cuts response bloat by ~75%, keeping interaction fast and dense
- **Grill-me-with-docs** prevents premature implementation by forcing design clarity first
