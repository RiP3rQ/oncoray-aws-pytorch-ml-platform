# Issue Tracker

Issues for this repo are tracked in Linear via the configured MCP integration.

Do not use `gh issue`, `glab`, or local markdown issue files for normal issue work in this repo.

When a skill needs to read, create, update, or triage issues:

- Use the Linear MCP tools/resources available in the current session.
- Keep issue titles, labels, states, and comments in Linear.
- If Linear MCP access is unavailable, ask the user before falling back to another workflow.
